# CGPA Prediction Dashboard

A complete Machine Learning based CGPA prediction system with a professional Streamlit dashboard.

## Dashboard Features

- Professional UI
- Sidebar student input form
- CGPA prediction
- Performance category
- KPI cards
- Academic score chart
- Dataset CGPA distribution chart
- Recent prediction history
- Model accuracy information

## Inputs

- Previous CGPA
- Attendance percentage
- Study hours per day
- Assignment score
- Midterm score
- Final exam score

## Technology

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Linear Regression

## Run Project

Open terminal inside the project folder:

```bash
pip install -r requirements.txt
streamlit run app.py
```

The dashboard will open in your browser.

## Note

The included student dataset is demo/sample data for academic learning.
For a final university project, replace it with real anonymized student data.
